# Post-H2 Phase 4A — Theme Synchrony Closeout

**Status:** CLOSED — NO EXPLORATORY THEME-SYNCHRONY FLAG SURVIVED MULTIPLE-TESTING CONTROL

## Scope

Phase 4A tested whether securities sharing the frozen evidence-based structural themes were more synchronized than random same-sized groups drawn from the same 30 preselected top-driver securities.

The protocol was frozen before Phase 4A statistics were inspected.

- Randomization replications per eligible theme: 20,000
- Seed: 20260824
- Control universe: same 30 Phase 3A top-driver securities
- Structural themes tested with randomization: 8
- Structural themes descriptive only because n < 3: 2
- Multiple-testing correction: Holm, separately for contribution synchrony and active-count/commonality correlation
- H1/H2 modifications: 0

## Contribution-Synchrony Result

No tested structural theme survived Holm correction.

The strongest nominal result was:

- S06 — Digital Platform / Monetization Shift
- n = 4
- average pairwise contribution correlation = +0.1879
- one-sided Monte Carlo p = 0.0495
- Holm-adjusted p = 0.3960

Therefore it is not an exploratory multiple-testing-adjusted flag.

Other observed contribution-synchrony results were also positive but not unusually large relative to same-sized random groups from the selected top-30 universe:

- S02 Power / Energy Infrastructure: +0.1359, Holm p = 0.6594
- S04 Commodity / Resource Scarcity & Pricing: +0.0913, Holm p = 1.0000
- S03 Electrification / Energy Transition: +0.0836, Holm p = 1.0000
- S01 AI / Compute / Digital Infrastructure: +0.0690, Holm p = 1.0000
- S05 Capacity Expansion / Supply-Demand Imbalance: +0.0619, Holm p = 1.0000
- S09 Strategic Consolidation / Portfolio Scale: +0.0588, Holm p = 1.0000
- S08 Real-Asset Occupancy / Demographic Demand: +0.0126, Holm p = 1.0000

## Strong-Month Clustering Result

No structural theme's monthly active-Winner count was unusually positively associated with absolute residual commonality after Holm correction.

All Holm-adjusted p-values for this metric were 1.0000.

Therefore the evidence-defined themes did not identify a statistically unusual concentration of active Winners during high-commonality months within the selected top-30 universe.

## Interpretation

Phase 4A does not support the idea that the frozen structural themes explain the residual commonality through unusually synchronized contribution behavior.

This does not invalidate the primary-source evidence or the taxonomy. It means the evidence-defined groups are descriptively meaningful but do not display stronger contribution synchronization than random same-sized subsets of the already-selected top-driver securities after multiple-testing control.

The correct response is not to retune the taxonomy.

## Decision

**CLOSED — NO ADJUSTED THEME-SYNCHRONY SIGNAL**

The thematic commonality branch is retained as descriptive context only.

A possible H3 involving public attention must be treated as a new hypothesis with separately frozen data sources, variables, timing rules, and inference. It may not be presented as a rescue of H2 or Phase 4A.
